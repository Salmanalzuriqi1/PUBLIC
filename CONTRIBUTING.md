# Contributing Guide

We welcome contributions to improve and develop this project! Please follow these guidelines to contribute effectively:

1. **Reporting Issues:** If you find a bug or encounter an issue, please open a new Issue with a detailed description.
2. **Pull Requests:** 
   - Fork the repository.
   - Create a new branch for your changes (`git checkout -b feature/YourFeature`).
   - Commit your changes and ensure necessary tests pass.
   - Submit a Pull Request to the `main` branch.
3. **Code Standards:** Please adhere to clean code principles and maintain proper documentation.

Thank you for contributing to **Sulta Digital**!
